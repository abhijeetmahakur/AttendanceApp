# Security Policy

This project has no formal release or supported-version policy. Reports should identify the latest version on the default branch and the affected deployment configuration.

Do not disclose vulnerability details in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab and **Report a vulnerability**. If that option is unavailable, ask the repository owner through an already-established private channel how to share a report; do not post exploit details publicly. Do not include credentials, student records, or other personal data in a report.

Please allow time for investigation and a fix before public disclosure. No response-time guarantee is currently defined.
